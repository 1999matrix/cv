Description

After uninstalling the CUSA agent, multiple folders, files, and sensitive data remain on the system. These artifacts include plaintext credentials, API tokens, machine keys, telemetry queue data, agent state, logs, UI data, and Windows Error Reporting crash dumps.

A security agent must remove all traces on uninstall. Leaving behind credentials and telemetry is a critical security and compliance issue.
